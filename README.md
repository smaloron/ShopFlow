Présentation
ShopFlow est un projet pédagogique dont l'objectif est de construire une application microservices. Il est organisé en 5 labs.

- Lab 1 : Domain-Driven Design (DDD), la Clean Architecture et le CQRS
- Lab 2 : Mediator, API Gateway et commnication
- Lab 3 : Messaging asynchrone
- Lab 4 : Résilience, sécurité et observabilité
- Lab 5 : Orchestration et déploiement
